HYPERPARAMETER OPTIMIZATION STUDY

From baseline to optimized.

A quantitative comparison of the PyTorch Quickstart tutorial model and our HPO-tuned convolutional network across the 10,000-image FashionMNIST test split.

01 / QUICKSTART BASELINE

5-Epoch MLP

Following the official PyTorch Quickstart tutorial, inputs are flattened into 784 features and trained with SGD (lr=0.001, batch=64) for 5 epochs. Under-training and lack of spatial filters limit accuracy on overlapping tops.

02 / HPO SWEEP

Systematic Search

We evaluated learning rates (1e-3 to 1.5e-2), SGD+Momentum vs. AdamW, batch sizes (32, 64, 128), cosine/step LR schedules, dropout, weight decay, and geometric augmentations on a 54k/6k validation split.

03 / OPTIMIZED CNN

Spatial Hierarchy

Pairing 3×3 convolutional blocks with BatchNorm, GELU, Flip+Affine augmentation, AdamW, and CosineAnnealingLR resolves collar and sleeve ambiguities, cutting classification error rate by over 75%.

CONTAINER ARCHITECTURE

Cog + FastAPI separation.

All PyTorch model weights are verified by SHA-256 checksum and loaded once inside the Cog inference container using safetensors. The web container validates uploads, strips EXIF metadata, and calls Cog over the internal Docker network.

LOCAL & DETERMINISTIC

Stay fast.
Stay verifiable.

Prediction events are logged inside the running Cog container at /tmp/garment-predictions.jsonl without storing any user pixel bytes or filenames.
